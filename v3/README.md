# ASGK 3.0 — 可測試實驗版

**讓人與 AI 能安全、順利交接工作的規則與工具。**

看得懂：清楚的工作狀態與邊界。接得下去：不靠舊對話恢復工作。
查得清楚：決策、理由與檔案證據可快速追溯。

這是獨立分支上的離線原型，不是已發布的 ASGK 3.0。現有 2.0 流程未搬移。
先測試「集中維護規則 → 編譯本次最小工作包 → 交接 → 證據與決策摘要」，
再決定哪些設計值得搬移。設計契約見 [DESIGN.md](DESIGN.md)。

## 五分鐘試用

需要 Python 3.10+，不需安裝套件、帳號或模型。

```bash
python3 v3/asgk3.py demo --out /tmp/asgk3-first-test
python3 -m unittest discover -s v3 -p 'test_*.py' -v
```

`--out` 必須尚不存在；重跑請換目錄。輸出包含輸入契約、工作包、模擬工作檔、
報告、交接與 closeout。示範的角色、證據與接手都是合成資料，不是跨供應商實證。
手動測試与失敗案例見 [TESTING.md](TESTING.md)。

## 已做／未做

已做：明確路徑與工具名稱的範圍交集、有效期／撤銷檢查、內容綁定、最小讀取指標、
本機證據雜湊、接手包、可搜尋的決策摘要、對抗性測試。

未做：真實身份驗證、OS sandbox、即時撤銷、工具攔截、Bot 派工、模型切換、
真實跨供應商／人類接手測試。**檢查通過不等於授權，也不證明 Agent 沒碰其他檔案。**
本原型不執行契約內的工具名稱或 validation 文字。

現有 ASGK 文件是 2.0 的權威；`v3/` 是非預設實驗，不得用它繞過現有流程。
實驗紀錄與交付狀態見 [HANDOFF.md](HANDOFF.md)。
